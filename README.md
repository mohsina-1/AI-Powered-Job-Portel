AI-Powered Job Portal

Project Overview

The AI-Powered Job Portal is a web-based application developed using Python and Django. It connects job seekers and employers through an intelligent job recruitment platform.

Main Modules

1. Job Seeker Module

- User registration and login
- Create and update profile
- Upload resume in PDF format
- Search and filter job vacancies
- Apply for jobs
- Track application status
- View AI-recommended jobs

2. Employer Module

- Employer registration and login
- Create and manage job vacancies
- View applicants
- Review candidate resumes
- Filter applicants based on skills
- Update application status

3. AI Module

- AI Resume Analyzer
- Smart Job Recommendation
- Skill Gap Analysis
- AI Interview Question Generator

Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite

Project Purpose

To simplify the recruitment process by connecting job seekers and employers and providing intelligent features for better job matching.
